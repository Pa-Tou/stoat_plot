# Dot Plot of snarl type histogram

Create a histogram plot from a TSV file containing a \`path_length\`
column.

## Usage

``` r
snarl_type_histogram(input, output = NULL)
```

## Arguments

- input:

  Path to the input TSV file.

- output:

  Path to save the output plot image.

## Value

Saves a histogram plot to the specified file.
