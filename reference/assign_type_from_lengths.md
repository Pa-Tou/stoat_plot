# Assign a variant type from ALLELE_LENGTHS field

Assign a variant type from ALLELE_LENGTHS field

## Usage

``` r
assign_type_from_lengths(al_lens)
```

## Arguments

- al_lens:

  a vector of allele lengths formatted as in ALLELE_LENGTHS, e.g.
  1,0,10/56

## Value

a vector of characters with the variant types
