## Overview

`StoatPlot` provides a set of lightweight and user-friendly tools for
visualizing **GWAS results** generated by the [**STOAT**
tool](https://github.com/pa-tou/stoat). It includes functions for
generating:

- **Manhattan plots**
- **Q-Q plots**
- **P-value histograms**
- **Genotype-based boxplots**
- **Paths length distribution**
- **Snarl type histogram**

These tools facilitate the visual inspection of association signals and
support downstream interpretation of GWAS outputs.

| [`summary_stoat()`](https://pa-tou.github.io/stoat_plot/reference/summary_stoat.md) | Print summary information on GWAS results |

| [`plot_pvalue_hist()`](https://pa-tou.github.io/stoat_plot/reference/plot_pvalue_hist.md) | Histogram of p-values from GWAS |
| [`genotype_boxplots()`](https://pa-tou.github.io/stoat_plot/reference/genotype_boxplots.md) | Boxplots of phenotype values by genotype |
| [`path_length_distribution()`](https://pa-tou.github.io/stoat_plot/reference/path_length_distribution_all.md) | Dot Plot of Path Length Frequencies |
| [`snarl_type_histogram()`](https://pa-tou.github.io/stoat_plot/reference/snarl_type_histogram.md) | Dot Plot of snarl type histogram |

## Sorting and indexing snarl genotypes

To speed up the visualization of associations,
[`genotype_boxplots()`](https://pa-tou.github.io/stoat_plot/reference/genotype_boxplots.md)
extracts the relevant genotypes from an indexed and bgzipped TSV file.
To index a `snarl_genotypes.tsv.gz` (output of `stoat vcf` or
`stoat graph`) with `bgzip` and `tabix`:

``` sh
(zcat snarl_genotypes.tsv.gz | head -10000 | grep "^#"; zgrep -v "^#" snarl_genotypes.tsv.gz | sort -k3,3n -k4,4n -k5,5n) | bgzip > snarl_genotypes.sorted.tsv.gz
tabix -f -c "#" -s 3 -b 4 -e 5 snarl_genotypes.sorted.tsv.gz
```

You can then use the `snarl_genotypes.sorted.tsv.gz` file as input to
the `genotype_boxplots` function (*genotype_file* parameter).
